# Uniqly

Десктопное приложение для подготовки коротких вертикальных видео (Reels /
Shorts / TikTok): скачивает ролик по ссылке, уникализирует его под заданный
пресет и складывает результат в галерею с описанием.

Написано на PySide6, работает на macOS и Windows. ffmpeg вшивается внутрь
собранной программы, поэтому у пользователя не нужно ничего доустанавливать.

## Что делает

**Конвейер одного ролика**
1. скачивание по ссылке (YouTube / Instagram) через yt-dlp — куки берутся из
   браузера, чтобы работали закрытые источники
2. автодетект чёрных полос (ffmpeg `cropdetect`) и ручная правка рамки мышкой
3. уникализация: зум, повышение резкости, сдвиг контраста и насыщенности,
   изменение темпа, зерно — параметры каждый раз разные
4. предпросмотр кадра и отрезка **до** полного рендера
5. описание фильма подтягивается по названию из КиноПоиска
6. готовый файл — в галерею, с историей в SQLite

**Пакетная обработка**
Список ссылок обрабатывается в два независимых пула: скачивание идёт
параллельно (сеть), рендер — последовательно (процессор). Первый ролик
задаёт рамку кропа, остальные пересчитывают её пропорционально своему
разрешению.

**Пресеты уникализации**

Все три дают кадр 1080×1920 и различаются тем, чем заполнены поля:

| Пресет | Поля по краям | Особенности |
|---|---|---|
| `reels` | размытый кадр видео | вотермарк поверх |
| `crop` | чёрные | центр-кроп |
| `tiktok` | белый фон | надпись-хук поверх видео |

В интерфейсе кодовых слов нет: пользователь выбирает фон и нужен ли
логотип, а `channels.preset_for()` переводит это в имя пресета. Каналы
тоже не зашиты в код — создаются во вкладке «Настройки» и живут в базе.

## Технические решения

Несколько мест, где пришлось разбираться глубже, чем ожидалось:

**Прогресс скачивания.** yt-dlp сообщает проценты *по каждому файлу
отдельно*, а видео и звук качаются раздельно — из-за этого индикатор
прыгал (100 → 17 → 50). Внутри хука общий размер узнать нельзя:
`info_dict` во время загрузки содержит только текущий файл. Решение —
считать сумму размеров заранее, отдельным `extract_info(download=False)`,
и передавать её в хук. Для HLS-потоков, где размера нет вообще, прогресс
считается по числу загруженных фрагментов.

**Скорость звука.** Фильтр `asetrate` объявляет «играть эти сэмплы с
частотой X». Если зашить 44100 для файла с 48000 Гц, звук растягивается на
8.8% и уезжает от картинки. Частота читается из исходника.

**Качество и размер.** Уровни качества задают не только разрешение, но и
сдвиг CRF: без него файл 480p занимал 47% от размера 1080p вместо
ожидаемых 30% — кодек тратил биты на шум, а не на детали.

**ffmpeg внутри программы.** Сборка от Homebrew тянет 53 динамические
библиотеки и в комплект не годится — нужны статические сборки. Ни один
вызов не обращается к `ffmpeg` по голому имени: путь резолвит
[`app/binaries.py`](app/binaries.py) — вшитый в сборке, системный при
запуске из исходников.

**Рабочая папка.** Внутрь собранного `.app` macOS запрещает писать,
поэтому данные живут в папке пользователя (`~/Library/Application Support`
или `%APPDATA%`), а при запуске из исходников — рядом с кодом.

## Стек

| Слой | Технология |
|---|---|
| Интерфейс | PySide6 (Qt 6) |
| Видео | ffmpeg / ffprobe (вшиты в сборку) |
| Скачивание | yt-dlp |
| Хранение | SQLite + автоматические бэкапы |
| Картинки | Pillow |
| Сеть | httpx |
| Распознавание текста | tesseract (опционально) |
| Сборка | PyInstaller |

## Структура

```
uniqly/
├── app/
│   ├── main.py            # точка входа
│   ├── config.py          # пути, рабочая папка, .env
│   ├── binaries.py        # резолв ffmpeg/ffprobe
│   ├── channels.py        # реестр каналов (из базы) и пресетов
│   ├── pipeline.py        # конвейер download → uniqueize → preview
│   ├── downloader.py      # yt-dlp и расчёт прогресса
│   ├── batch_runner.py    # пакетная обработка, два пула задач
│   ├── quality.py         # уровни качества (разрешение + сдвиг CRF)
│   ├── storage.py         # SQLite, история, бэкапы
│   ├── kinopoisk.py       # описание фильма
│   ├── ocr.py             # чтение надписи с кадра
│   └── gui/               # вкладки, галерея, редакторы кропа и параметров
├── processors/
│   ├── uniq.py            # параметры уникализации и фильтры ffmpeg
│   ├── reels.py           # пресет reels
│   ├── crop.py            # пресет crop
│   ├── tiktok.py          # пресет tiktok
│   ├── caption.py         # отрисовка надписи-хука
│   └── cropdetect.py      # автодетект чёрных полос
└── uniqly.spec            # сборка PyInstaller
```

## Запуск из исходников

Нужны Python 3.11 и ffmpeg в системе.

```bash
python3.11 -m venv venv && source venv/bin/activate
pip install -r requirements-app.txt
python -m app.main
```

## Сборка

```bash
./fetch_ffmpeg.sh                      # статический ffmpeg внутрь программы
pyinstaller uniqly.spec --noconfirm    # → dist/Uniqly.app
```

Windows-сборка — через GitHub Actions
([`.github/workflows/build-windows.yml`](.github/workflows/build-windows.yml)).

Готовая программа не подписана сертификатом разработчика, поэтому при первом
запуске система предупредит о неизвестном авторе.
